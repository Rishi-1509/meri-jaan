# 🎵 Audio Soundtrack Folder

Drop your audio files directly into this directory!

### Recommended songs configured:
1. `singari.mp3` (for "Singari" by Sai Abhyankkar)
2. `watcha-udatha.mp3` (for "Watcha Udatha")

### How it works:
- If you place `singari.mp3` here, the website will play your local audio file directly in high fidelity.
- If you don't place an MP3 file here, the website uses a built-in gentle romantic chime audio synthesizer and provides a 1-click button to listen to the official track on YouTube / Spotify.
- Edit `src/data/siteConfig.ts` under `playlist` to change the song titles, artists, or audio paths.
